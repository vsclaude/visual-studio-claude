# Keyboard shortcuts

Written for macOS. On Windows and Linux, read `⌘` as `Ctrl`. Inside a terminal
on those systems, the `Ctrl` letters belong to the shell (`Ctrl+W` deletes a
word there), so VS Claude leaves them alone.

## Window

| Keys      | Does                                 |
| --------- | ------------------------------------ |
| `⌘P`      | Command palette: find a file or chat |
| `⇧⌘F`     | Search in every file and chat        |
| `⌘B`      | Show or hide the projects column     |
| `⌘,`      | Settings                             |
| `` ⌃` ``  | Show or hide the terminal            |
| `` ⌃⇧` `` | A new terminal                       |

`` ⌃` `` is `Ctrl` on every system, macOS included.

## Tabs

| Keys                            | Does                           |
| ------------------------------- | ------------------------------ |
| `⌘1` … `⌘8`                     | The n-th tab                   |
| `⌘9`                            | The last tab                   |
| `⌘⇧[` / `⌘⇧]`                   | The tab to the left / right    |
| `Ctrl+PageUp` / `Ctrl+PageDown` | The same, on Windows and Linux |
| `Ctrl+Tab` / `Ctrl+⇧Tab`        | The next / previous tab        |
| `⌘W`                            | Close the tab                  |
| `⌘S`                            | Save the open file             |

## Chat

| Keys          | Does                                    |
| ------------- | --------------------------------------- |
| `Enter`       | Send                                    |
| `Shift+Enter` | A new line                              |
| `@`           | Mention a file or folder of the project |
| `⌘F`          | Find in the conversation                |

## Git

| Keys | Does                              |
| ---- | --------------------------------- |
| `⌘⏎` | Commit, in the commit message box |
