# Phím tắt

Viết cho macOS. Trên Windows và Linux, đọc `⌘` thành `Ctrl`. Trong terminal trên
các hệ điều hành đó, các phím `Ctrl` + chữ thuộc về shell (`Ctrl+W` xoá một từ),
nên VS Claude không chiếm chúng.

## Cửa sổ

| Phím      | Làm gì                              |
| --------- | ----------------------------------- |
| `⌘P`      | Command palette: tìm file hoặc chat |
| `⇧⌘F`     | Tìm trong mọi file và chat          |
| `⌘B`      | Hiện hoặc ẩn cột project            |
| `⌘,`      | Settings                            |
| `` ⌃` ``  | Hiện hoặc ẩn terminal               |
| `` ⌃⇧` `` | Mở terminal mới                     |

`` ⌃` `` là `Ctrl` trên mọi hệ điều hành, kể cả macOS.

## Tab

| Phím                            | Làm gì                          |
| ------------------------------- | ------------------------------- |
| `⌘1` … `⌘8`                     | Tab thứ n                       |
| `⌘9`                            | Tab cuối cùng                   |
| `⌘⇧[` / `⌘⇧]`                   | Tab bên trái / bên phải         |
| `Ctrl+PageUp` / `Ctrl+PageDown` | Như trên, trên Windows và Linux |
| `Ctrl+Tab` / `Ctrl+⇧Tab`        | Tab tiếp theo / trước đó        |
| `⌘W`                            | Đóng tab                        |
| `⌘S`                            | Lưu file đang mở                |

## Chat

| Phím          | Làm gì                                 |
| ------------- | -------------------------------------- |
| `Enter`       | Gửi                                    |
| `Shift+Enter` | Xuống dòng                             |
| `@`           | Nhắc tới file hoặc thư mục của project |
| `⌘F`          | Tìm trong cuộc trò chuyện              |

## Git

| Phím | Làm gì                              |
| ---- | ----------------------------------- |
| `⌘⏎` | Commit, khi đang ở ô commit message |
